# Office Master 🚗

Projeto da disciplina de programação de dispositivos móveis com ReactNative + Expo (Android)

**Orientador:** Prof. Kesede Rodrigues Julio

A solução compartilhada neste repositório consiste no desenvolvimento de uma plataforma mobile para gerenciamento completo de oficinas mecânicas automotivas, permitindo controle de clientes, ordens de serviço, agendamentos e estoque de forma organizada e digital, substituindo o método tradicional de controle manual em papel.

## 🔧 Requisitos

* **NodeJS LTS** versão 20.x.x ou superior
* **React Native** versão 0.76.x
* **Expo SDK** ~52.0.0
* **ExpoGo:** [Android](https://play.google.com/store/apps/details?id=host.exp.exponent) / [iOS](https://apps.apple.com/app/expo-go/id982107779)
* **Banco de dados:** Firebase (Firestore + Authentication)

### 🗃️ Estrutura do Firebase Firestore:

**Coleção 'users':**
```
id: string (auto-generated by Firebase)
email: string (not null)
name: string (nullable)
createdAt: timestamp
```

**Coleção 'clients':**
```
id: string (auto-generated by Firebase)
userId: string (foreign key - users.id)
name: string (not null)
phone: string (nullable)
email: string (nullable)
address: string (nullable)
vehicle: string (nullable)
createdAt: timestamp
updatedAt: timestamp
```

**Coleção 'serviceOrders':**
```
id: string (auto-generated by Firebase)
userId: string (foreign key - users.id)
clientId: string (foreign key - clients.id)
clientName: string
description: string
status: string (enum: 'pending', 'in_progress', 'completed', 'cancelled')
value: number
createdAt: timestamp
updatedAt: timestamp
```

**Coleção 'schedules':**
```
id: string (auto-generated by Firebase)
userId: string (foreign key - users.id)
clientId: string (foreign key - clients.id)
clientName: string
date: timestamp
time: string
description: string
status: string (enum: 'scheduled', 'confirmed', 'in_progress', 'completed', 'cancelled')
createdAt: timestamp
```

**Coleção 'inventory':**
```
id: string (auto-generated by Firebase)
userId: string (foreign key - users.id)
name: string (not null)
category: string
quantity: number
minQuantity: number
price: number
createdAt: timestamp
updatedAt: timestamp
```

## 🔐 Configuração de acesso aos dados

Para configurar o acesso ao Firebase, você precisa criar um arquivo de configuração com suas credenciais:

1. Crie um projeto no [Firebase Console](https://console.firebase.google.com/)
2. Ative **Authentication** (Email/Password)
3. Ative **Firestore Database**
4. Copie as credenciais do seu projeto
5. Configure o arquivo `frontend/src/config/firebaseConfig.ts`:

```typescript
export const firebaseConfig = {
  apiKey: "SUA_API_KEY_AQUI",
  authDomain: "seu-projeto.firebaseapp.com",
  projectId: "seu-projeto-id",
  storageBucket: "seu-projeto.appspot.com",
  messagingSenderId: "123456789",
  appId: "1:123456789:web:abcdef"
};
```

> ⚠️ **IMPORTANTE:** Nunca compartilhe suas credenciais do Firebase publicamente!

## 📦 Instale os requisitos do projeto

### Instruções para instalação em um computador com **Windows 11**

Caso não tenha o **chocolatey** instalado, inicie o preparo do sistema abrindo um terminal do PowerShell com privilégio de administrador:

```powershell
PS> Set-ExecutionPolicy AllSigned
```

```powershell
PS> Set-ExecutionPolicy Bypass -Scope Process -Force; [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072; iex ((New-Object System.Net.WebClient).DownloadString('https://chocolatey.org/install.ps1'))
```

```powershell
PS> choco --version
```

Com o **chocolatey** instalado, continuamos com a instalação dos requisitos do projeto:

```powershell
PS> choco install nodejs-lts -y
PS> choco install openjdk17 -y
```

### Instruções para **macOS**

```bash
# Instalar Homebrew (se não tiver)
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Instalar NodeJS
brew install node
```

### Instruções para **Linux (Ubuntu/Debian)**

```bash
# Atualizar repositórios
sudo apt update

# Instalar NodeJS
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs
```

### Instalar dependências do projeto

Após instalar os requisitos do sistema, navegue até a pasta do frontend e instale as dependências:

```bash
cd frontend
npm install
```

## 🚀 Executando o projeto

1. Certifique-se de ter configurado o Firebase (veja seção [Configuração de acesso aos dados](#-configuração-de-acesso-aos-dados))

2. Navegue até a pasta do frontend:
```bash
cd frontend
```

3. Inicie o projeto:
```bash
npx expo start
```

4. Abra o aplicativo **Expo Go** no seu smartphone

5. Escaneie o QR Code exibido no terminal

> **Dica:** Certifique-se de que seu computador e smartphone estão na mesma rede Wi-Fi

## 📱 Telas do projeto

### Tela 1: Login
Tela de autenticação onde o usuário insere email e senha para acessar o sistema.

**Funcionalidades:**
- Login com email e senha
- Validação de campos
- Link para criação de conta
- Link para recuperação de senha

---

### Tela 2: Cadastro de Usuário
Tela para criação de nova conta no sistema.

**Funcionalidades:**
- Cadastro com nome, email e senha
- Validação de email único
- Validação de força da senha
- Confirmação de senha

---

### Tela 3: Recuperação de Senha
Tela para redefinição de senha via email.

**Funcionalidades:**
- Envio de email de recuperação
- Validação de email cadastrado
- Feedback de sucesso/erro

---

### Tela 4: Home (Tela Inicial)
Dashboard principal com resumo das informações da oficina.

**Funcionalidades:**
- Estatísticas rápidas (clientes, ordens de serviço, agendamentos)
- Acesso rápido aos módulos principais
- Menu do usuário (perfil e logout)
- Pull-to-refresh para atualizar dados

---

### Tela 5: Lista de Clientes
Visualização de todos os clientes cadastrados na oficina.

**Funcionalidades:**
- Listagem completa de clientes
- Busca por nome, telefone ou email
- Acesso aos detalhes do cliente
- Botão para adicionar novo cliente

---

### Tela 6: Adicionar Cliente
Formulário para cadastro de novo cliente.

**Funcionalidades:**
- Campos: nome, telefone, email, endereço, veículo
- Validação de campos obrigatórios
- Salvamento no Firebase
- Navegação automática para lista após sucesso

---

### Tela 7: Detalhes do Cliente
Visualização completa das informações do cliente.

**Funcionalidades:**
- Exibição de todos os dados do cliente
- Histórico de ordens de serviço
- Opções de editar ou excluir cliente
- Compartilhamento de informações

---

### Tela 8: Editar Cliente
Formulário para edição de dados do cliente.

**Funcionalidades:**
- Campos pré-preenchidos com dados atuais
- Validação de alterações
- Atualização no Firebase

---

### Tela 9: Lista de Ordens de Serviço
Gerenciamento de todas as ordens de serviço.

**Funcionalidades:**
- Listagem com filtros por status
- Busca por cliente ou descrição
- Indicadores visuais de status
- Botão para criar nova ordem

---

### Tela 10: Adicionar Ordem de Serviço
Criação de nova ordem de serviço.

**Funcionalidades:**
- Seleção de cliente
- Descrição do serviço
- Definição de valor
- Status inicial (pendente)

---

### Tela 11: Detalhes da Ordem de Serviço
Visualização completa da ordem de serviço.

**Funcionalidades:**
- Informações detalhadas da OS
- Alteração de status
- Edição de dados
- Exclusão da ordem

---

### Tela 12: Lista de Agendamentos
Calendário e lista de agendamentos da oficina.

**Funcionalidades:**
- Visualização em calendário
- Lista de agendamentos do dia
- Filtros por status e data
- Botão para novo agendamento

---

### Tela 13: Adicionar Agendamento
Criação de novo agendamento.

**Funcionalidades:**
- Seleção de cliente
- Escolha de data e horário
- Descrição do serviço
- Confirmação de disponibilidade

---

### Tela 14: Detalhes do Agendamento
Informações completas do agendamento.

**Funcionalidades:**
- Dados do agendamento
- Alteração de status (confirmar, iniciar, concluir, cancelar)
- Notificações ao cliente

---

### Tela 15: Estoque/Inventário
Gerenciamento de peças e materiais.

**Funcionalidades:**
- Listagem de itens do estoque
- Filtros por categoria
- Indicador de estoque baixo
- Adição e edição de itens

---

### Tela 16: Perfil do Usuário
Informações e configurações da conta.

**Funcionalidades:**
- Dados do usuário logado
- Edição de perfil
- Opção de logout

## 🎓 Contexto Acadêmico

Este projeto foi desenvolvido como trabalho da disciplina de **Programação para Dispositivos Móveis** e como projeto de **Extensão Universitária**, visando solucionar um problema real de gestão em oficinas mecânicas.

**Problema identificado:** Oficinas mecânicas realizavam controle de chamados e serviços em folhas de papel, gerando desorganização, perda de informações e dificuldade de acompanhamento.

**Solução proposta:** Aplicativo mobile multiplataforma que centraliza todas as informações em uma plataforma digital acessível, organizada e eficiente.
